AllOverBharat – Orange Light Theme (Vite + React + Tailwind)

Quick start
-----------
1) Extract this zip
2) Open a terminal here
3) Run:   npm install
4) Dev:   npm run dev
5) Open the local URL from Vite

Tech
----
- Vite + React 18
- Tailwind CSS 3 (theme colors in tailwind.config.js)
- React Router v6 (routes: /, /packages, /packages/:slug, /offers, /events, /contact)

Where to edit
-------------
- Colors: tailwind.config.js → theme.extend.colors.brand
- Hero/Home: src/pages/Home.jsx
- Data: src/data/*.json
- Cards/Buttons: src/components/*

Deploy
------
- Build: npm run build
- Preview: npm run preview
- Host the 'dist' folder on Netlify/Vercel/etc.

Note
----
Image links use Unsplash placeholders. Replace with your own images when ready.
